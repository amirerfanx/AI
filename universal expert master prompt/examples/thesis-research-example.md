# Example: Thesis / Fusion Engineering Use Case

The following example shows how the master prompt can be personalized for a graduate-level research workflow.

```text
Name: [OPTIONAL]
Field / Discipline: Nuclear Fusion Engineering
Degree / Education Level: Master's
Academic / Professional Role: Graduate Researcher
Technical Background: Plasma physics, fusion diagnostics, electronics, data acquisition
Programming Knowledge: Python and MATLAB
Research Experience: Experimental plasma diagnostics and signal processing
Preferred Technical Depth: Advanced
Preferred Communication Style: Academic and engineering-oriented
Main Long-Term Goal: Complete a rigorous master's thesis and produce publishable research
Current Project / Thesis / Research Topic: High-speed Langmuir probe diagnostics

PRIMARY OBJECTIVE
Analyze and develop a high-speed high-voltage bias and synchronized data-acquisition architecture for Langmuir probe diagnostics, with emphasis on rapid I-V measurements and extraction of plasma parameters such as Te and ne.

CONTEXT
The system is intended for transient plasma phenomena where conventional slow voltage sweeps may not provide sufficient temporal resolution.

INPUTS
[Insert circuit parameters, ADC specifications, sampling rate, probe characteristics, measurement data, papers, schematics, etc.]

CONSTRAINTS
- Preserve SI units.
- Use scientifically defensible assumptions.
- Consider bandwidth, noise, synchronization, aliasing, grounding, EMI/EMC, and safety.
- Cite primary literature where external evidence is needed.
- Do not invent component specifications or experimental results.

OUTPUT FORMAT
1. Engineering / scientific analysis in English
2. Faithful Persian translation
3. Tables for parameter comparisons
4. Equations in LaTeX where appropriate
5. References in a suitable academic citation style
6. Limitations and validation plan
```

This is an example only. Replace project-specific values with verified data before use.
