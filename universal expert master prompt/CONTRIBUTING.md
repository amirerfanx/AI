# Contributing

Thank you for contributing to Universal Expert Master Prompt.

## What Makes a Good Contribution?

Useful contributions include:

- Improving clarity or reducing ambiguity
- Adding reusable prompt components
- Improving research and engineering safeguards
- Adding examples for new domains
- Fixing inconsistencies
- Improving bilingual terminology
- Improving documentation

## Contribution Guidelines

1. Keep additions broadly reusable.
2. Avoid domain-specific assumptions in the core prompt unless they are clearly marked as optional.
3. Do not add instructions that encourage fabricated facts, citations, measurements, or results.
4. Preserve the distinction between verified facts, assumptions, and uncertainty.
5. Keep the five-pass quality-control framework consistent unless there is a strong reason to change it.

## Suggested Process

1. Fork the repository.
2. Create a feature branch.
3. Make the change.
4. Update documentation or examples when relevant.
5. Submit a pull request describing what changed and why.
