# Humanize Writing — Pattern Reference

This file is an optional reference companion to `INSTRUCTIONS.md`. It is useful as project knowledge or as a reference document; the main operating rules are in `INSTRUCTIONS.md`.

## Core idea

A single stylistic feature rarely proves anything about authorship. The useful signal is pattern stacking: several predictable choices appearing together and repeatedly.

The goal is therefore not to “ban AI words.” The goal is to reduce predictable structure, generic rhetoric, redundant explanation, inflated significance, and uniform rhythm while preserving meaning and domain precision.

## Pattern families

| Family | Typical signal | Better editorial response |
|---|---|---|
| Structure | repeated topic → three points → mini-summary | vary paragraph shapes |
| Meta-writing | “this section discusses…” | state the substance directly |
| Significance inflation | “crucial”, “pivotal”, “transformative” | explain the concrete importance |
| Generic framing | “in today’s world…” | start with the actual issue |
| Repetitive transitions | “Moreover/Furthermore…” in every paragraph | keep only useful transitions |
| Symmetry | repeated “both X and Y” / balanced pairs | preserve only when logically meaningful |
| Rhythm | uniformly medium-length sentences | vary length and syntax naturally |
| Vagueness | “studies show”, “experts say” | name the supplied source or state the claim directly |
| Padding | “provide an analysis of” | use a direct verb when appropriate |
| Closure | “Therefore/Overall” at every paragraph end | let the paragraph end naturally |
| Lexical inflation | ornamental synonyms | use the simplest precise term |
| Punctuation fingerprint | heavy em-dashes/semicolons | reduce only when it improves flow |

## Sentence-level transformations

### Example 1 — directness

Generic:

“An analysis of the experimental results was conducted in order to evaluate the system performance.”

Natural:

“The experimental results were analyzed to evaluate system performance.”

### Example 2 — remove meta-writing

Generic:

“This section aims to provide a comprehensive overview of the proposed method.”

Natural:

“The proposed method combines the bias supply with synchronized current and voltage acquisition.”

### Example 3 — replace importance rhetoric with content

Generic:

“This is a crucial finding that has significant implications for the field.”

Natural:

“The result matters because the higher sampling rate captures transient changes that the slower acquisition scheme misses.”

Only use the second sentence when that mechanism is actually supported by the source text.

### Example 4 — reduce decorative transition

Generic:

“Furthermore, the system is compact. Moreover, it reduces wiring complexity. Additionally, it is easier to calibrate.”

Natural:

“The compact design reduces wiring complexity and simplifies calibration.”

### Example 5 — preserve uncertainty

Original:

“These results may indicate a reduction in noise.”

Wrong:

“These results demonstrate a reduction in noise.”

Correct editorial choice:

“These results may indicate a reduction in noise.”

Or, where supported:

“The results are consistent with lower noise levels.”

### Example 6 — do not replace technical repetition

“Electron temperature was obtained from the exponential region of the I–V characteristic.”

Do not rewrite “electron temperature” as “thermal parameter” just to avoid repetition.

## Paragraph-level diagnostics

Ask:

- Does the first sentence actually contain the main point?
- Is the paragraph explaining a real relationship or just restating the topic?
- Are all sentences similarly shaped?
- Is the final sentence doing new work?
- Could two sentences be merged without losing a distinction?
- Is a transition necessary?
- Is there a concrete example or mechanism already available that can replace an abstract claim?

## Common anti-pattern: the universal three-part answer

Weak generated structure:

1. broad introduction;
2. definition;
3. three benefits;
4. limitation;
5. “future research” sentence.

Use that structure only when the content naturally requires it.

## Common anti-pattern: stacked adjectives

Weak:

“a highly robust, innovative, comprehensive, and transformative framework”

Prefer:

“a framework that reduces acquisition latency and supports synchronized sampling.”

Only state benefits supported by the source material.

## Common anti-pattern: abstract nouns stacked together

Weak:

“the implementation of an optimization of the configuration of the acquisition architecture”

Prefer:

“optimizing the acquisition architecture.”

## Common anti-pattern: fake individuality

Do not add:

- “I’ll be honest…”
- “Here’s the thing…”
- “To be fair…”
- intentional fragments;
- filler words;
- slang;
- fake personal reactions.

Natural writing can be straightforward without performing personality.
